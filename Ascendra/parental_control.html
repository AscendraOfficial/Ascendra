Kids mode is a way to get kids more interested in using Ascendra. In order to activate this function, the kids parents will need to log in or sign up to take more control over the kids account. if you want to activate kids mode, please fill in the form underneath.

Parent Verification

Sign in using your existing Ascendra account. This confirms that you are the parent or guardian.

Child Profile

Create Parent PIN

Create a 4-digit PIN for quick access to Parent Controls. This PIN will be required whenever someone attempts to:

  • Exit Kids Mode
  • Edit goals or habits
  • Manage rewards
  • Modify XP or coins
  • Change parental settings
  • Delete child data

Parent Notice

Ascendra Kids Mode is designed to encourage healthy habits, responsibility, and positive routines through age-appropriate challenges and rewards.

Parent Controls allow you to monitor progress, manage goals, approve rewards, and protect important settings.

Ascendra is intended to support—not replace—parental guidance. We encourage parents to review their child's progress regularly and celebrate achievements together.
