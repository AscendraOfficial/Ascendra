# Code of Conduct

Thank you for contributing to Ascendra!

To keep the project organized and enjoyable, please follow these guidelines.

## Be Respectful

- Treat everyone with kindness and respect.
- Give constructive feedback.
- Keep discussions professional and friendly.

## Discuss Changes First

- Talk about major features or changes before implementing them.
- Avoid making large changes without approval.
- If you're unsure, ask first.

## Write Quality Code

- Keep code clean and readable.
- Test your changes before committing.
- Follow the project's formatting and coding style.

## Keep Commits Clear

- Write meaningful commit messages.
- Keep commits focused on one change whenever possible.

## Respect the Project

- Do not remove or alter credits, licenses, or copyright notices.
- Do not intentionally break or damage the project.
- Respect the decisions of the project owner.

## Reporting Issues

If you find a bug or have an idea for an improvement, please open an issue or discuss it before making major changes.

---

Thank you for helping make Ascendra better! 🦊
