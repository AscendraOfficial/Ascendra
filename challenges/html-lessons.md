## Lesson 2: Page Structure

### Learn
A webpage uses doctype, html, head, title, and body.

### Example
```html

<html>
<head><title>My Page</title></head>
<body><h1>Welcome!</h1></body>
</html>
```

## Lesson 8: Forms

### Learn
Forms collect information. label describes an input.

### Example
```html
<form>
  <label for="name">Name:</label>
  <input id="name" name="name" type="text">
  <button type="submit">Send</button>
</form>
```

### Your challenge

## Lesson 9: Semantic HTML

### Learn
Semantic elements describe the role of content, improving structure and accessibility.

### Example
```html
<header><h1>My Site</h1></header>
<main><article><p>Hello!</p></article></main>
<footer>Made by Natalie</footer>
```

### Your challenge
