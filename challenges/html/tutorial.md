# HTML Tutorial 01: Basic Structure

## 1. Basic HTML Structure

Every HTML webpage starts with this structure:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>

</body>
</html>
```

## 2. Explanation

- `<!DOCTYPE html>` — Declares HTML5.
- `<html>` — Contains the entire HTML document.
- `<head>` — Stores information about the webpage.
- `<meta charset="UTF-8">` — Supports different characters and languages.
- `<meta name="viewport">` — Helps with mobile responsiveness.
- `<title>` — Sets the browser tab title.
- `<body>` — Contains everything visible on the webpage.

## 3. Adding Content

All visible content goes inside the `<body>`.

Example:

```html
<body>
    <h1>Hello World!</h1>
    <p>This is my first website!</p>
</body>
```
