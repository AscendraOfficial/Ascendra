# HTML
The JW branch uses HTML to make the base of webpages. In Ascendra, we use HTML 5,
the most modern version of HTML. This means that in each HTML page, you need to
include `<!DOCTYPE html>` at the very start of the page.

## Tags
It is easy to forget HTML tags, here are a list of the important HTML tags:

### Connecting tags
These are tags that connect HTML to other coding languages.

- `<link>` This tag is used to connect CSS. For example, `<link rel="stylesheet" href="style.css">`
- `<script>` This tag is uses to connect JavaScript. For example, `<script src="script.js"></script>`

### Text tags
These are tags that are related to writing text.

- `<h1>` This tag makes the largest heading you can make without CSS.
- `<h2>` This makes the second largest heading in HTML. 
- `<h3>` This makes the third largest heading in HTML.
- `<h4>` This makes the second smallest heading in HTML.
- `<h5>` This makes the smallest heading you can make in HTML.
- `<p>` This makes a paragraph.
- `<br>` This makes a line break in a paragraph, there is no closing tag for this tag.
