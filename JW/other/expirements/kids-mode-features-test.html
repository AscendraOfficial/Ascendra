A New Feature

Kids Mode

Ascendra developers have made a new feature called Kids Mode. In Kids Mode, we introduce many more kid-friendly features. Kids Mode included a new coin system and merchandise to buy. These are only a few features of Kids Mode, there are many more to come!

What's included

Merchandise

In Ascendra Kids Mode, you are able to buy merchandise with coins you earn from maintaining habits and completing todos. Merchandise can be worn on your Ascendra fox, making it much more unique!

Parental Controls

Kids Mode introduces parental controls, a tool to let parents observe and control what a kid is doing. This can help a child stay on the right track.

More colours

Developers are working to make Ascendra more colourful with different backgrounds, a decorated calendar and some general decoration around Ascendra.

Development

Creation

This idea of Kids Mode was suggested by Declan, as the lead developer of Ascendra. Ideas for what is in Kids Mode were made by Jayden. Declan is respnsible for all backend and Jayden is responsible for most of the frontend.

Bugs

Ascendra creators are working to fix any bugs that occur in Kids Mode. We have beta testers looking out for more problems. If you find any bugs in Kids Mode, try to avoid that section, as there might be irreversible changes made to your account.

Further development

Ascendra creators will continue working on Ascendra Kids Mode, making it cleaner, more convenient and more fun.
